# Hvordan konfigurere et public GitHub-repo for biblioteker?

Status: <mark style="background: #baf3db;">I BRUK</mark>

> [!IMPORTANT]
> Målet er at konfigurering av public GitHub-repoer for biblioteker skal kunne settes opp automatisk av `ssb-project`. Men vi er ikke helt der ennå, så inntil videre må man gjøre det manuelt som beskrevet her.

Hvordan du gjør et repo public er beskrevet under punkt 4 på [Hvordan opprette nytt GitHub-repo?](Hvordan%20opprette%20nytt%20GitHub-repo_.md). Etter at sikkerhetssenteret har gjort repoet public gjør du følgende:

1. Aktiver GitHub Pages med GitHub Actions som kilde. Det gjør det ved fullføre punkt 1 til 4 på denne lenken: <https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site#publishing-with-a-custom-github-actions-workflow>
