# Versjonskontroll med Git

Forvalter av siden: [KVAKK-gruppa](/wiki/spaces/KOD)

Status: <mark style="background: #baf3db;">I BRUK</mark>

## Introduksjon

Git er et verktøy for versjonskontroll. Det lagrer endringer på filer over tid, gjør det mulig å spore endringer og se tidligere versjoner av et prosjekt.

For å bruke git oppretter du et git repository i mappen som prosjektfilene ligger i hvor git sporer endringer og lagrer prosjektet sin historikk. Du kan dele ditt repository med andre og bruke git for å samordne endringer i et prosjekt.

Endringer gjøres ved at du lager en «commit» som består av et øyeblikksbilde av prosjektet, en commit-id, en kommentar, forfatter, dato og tid. Git gjør det enkelt å sammenligne ulike commits, som gjør at man kan lett kan se hva som har forandret seg mellom ulike versjoner, hvem som har gjort endringene og kommentarene som ble lagt ved endringene.
