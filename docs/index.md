## English summary

KVAKK is Statistics Norway's collection of rules, recommendations, and practical guidance on code quality and coding practices.
The documentation is written in Norwegian Bokmål, and primarily intended for developers working on statistical production at Statistics Norway.
It may also be useful to other organisations developing similar standards and practices.
